# 复制预览 1.6.2

面向 Android 16 / ColorOS 16.1 的 SystemUI 剪贴板预览模块。

- 修复键盘展开时浮窗上移：浮窗始终固定在屏幕左下角，关闭窗口层的键盘平移和内容层的键盘高度避让。
- 保留原生复制回调与编辑入口、ColorOS 高级模糊、自动文字与图标反色。
- 保留全向拖动、阈值划走、回弹，以及大小、字号、字重调节。显示时长为 1.0–5.0 秒，步进 0.1 秒。
- 移除 Send to device。

在一加 13T（PKX110_16.0.10.500(CN01)）实测，键盘展开与收起时卡片坐标完全一致，用户已确认。只作用于 SystemUI 主进程，APK 不申请权限，也不修改 Root 或隐藏配置。

安装需要支持 libxposed API 101 的 LSPosed。激活作用域仅选系统界面，重载 SystemUI 后生效。不要同时开启 LuckyTool 的“禁用复制悬浮窗”。

附件包含 APK、整理后的源码 ZIP、SHA256SUMS、APK 审计摘要和依赖许可证 ZIP。签名密钥、设备配置及日志不在仓库或附件中。

校验下载文件：

```sh
shasum -a 256 -c SHA256SUMS
```
