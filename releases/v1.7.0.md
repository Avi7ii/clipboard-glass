# 复制预览 1.7.0

修复升级 Android 17 / ColorOS 17 后复制浮窗失效的问题。

- 支持 SDK 37，保留 Android 16 的原有兼容路径。
- 适配原生异步复制处理，倒计时仍从复制回调发生时起算，不因后台排队延长。
- 适配新版编辑点击和完成回调，保留回桌面后点击编辑、编辑窗口获得焦点后关闭浮窗的行为。
- 使用新版 COUI 材质状态接口，恢复系统高级模糊及文字、图标随背景亮度切换黑白。
- 保留固定屏幕左下角、忽略键盘高度、全向拖动，以及大小、字号、字重调节。显示时长仍为 1.0–5.0 秒、0.1 秒步进。

在一加 13T 的 PKX110_17.0.0.104(CN01) 真机验证，用户确认预览、模糊、位置和编辑均正常。更新使用原签名，六份受保护配置（包括 HMA 隐藏配置）前后校验一致。作用域仍只限 SystemUI 主进程，无新增权限或 native library。

安装需要支持 libxposed API 101 的 LSPosed。已有用户覆盖安装 APK，重载 SystemUI 后生效。不要同时开启 LuckyTool 的“禁用复制悬浮窗”。

附件包含 APK、源码 ZIP、SHA256SUMS、APK 审计摘要和依赖许可证 ZIP；不含签名密钥、厂商 APK、设备配置及日志。

```sh
shasum -a 256 -c SHA256SUMS
```
